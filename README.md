# 恐龍防線 Dino Defense

手機（直向／橫向）與電腦都能玩的恐龍世界塔防網頁遊戲。線上試玩：https://allen640107-gh.github.io/tower-defense-web/

- **v2.1：16 關、7 個章節**，關卡選單是可點選的世界地圖（Grok Imagine 繪製）；有單一路線、**分岔路**與**雙入口**關卡，夜晚與特殊天氣版本，每章最後一關是章節魔王，暴龍王是最終關
- 7 種塔（各 3 級，可升級／賣出 70%）：石矛塔、火山投石、冰晶塔、毒液花、特斯拉電塔、琥珀晶塔、火把塔（夜晚照明）
- **塔的進化**：6 種戰鬥塔升到 3 級後可二選一進化，共 12 種（外觀、子彈、效果都不同，賣出仍退 70%）
- **英雄**：原始人獵人・岩牙／馴龍師・翠拉，可拖曳或「點英雄再點地點」移動，自動攻擊、升級、大招有冷卻，倒下後倒數復活
- **馴服恐龍**：擊倒的地面恐龍有機率成為友軍（上限 3，馴龍師 4），魔王與飛行恐龍不可收服，圖鑑記錄收服次數
- **天氣與晝夜**：雨（火弱電強）、霧（射程縮短）、暴風雪（恐龍變慢、冰更強）、火山灰（火更強）；夜晚只有照明範圍內的恐龍能被攻擊
- 8 種恐龍：迅猛龍、三角龍、甲龍、翼龍、副櫛龍、棘龍、腕龍；7 隻魔王：牛角暴君、沼澤巨鱷、風神翼龍、長毛象王、熔岩龍、迅猛龍女王、暴龍王
- 主動技能（冷卻）：隕石、尖刺陷阱、空投補給；道具：草藥、冰凍炸彈、金幣袋、炸藥
- 環境互動：可敲碎岩石／琥珀岩、沼澤泥坑減速、火山噴氣口、恐龍蛋孵化；關卡事件：空投、翼龍群、落石、寒流、火山爆發、孵化、流星雨
- 恐龍圖鑑（含收服紀錄）、10 種化石、16 項成就；存檔在 localStorage（`dino_save_v1`，會讀取並遷移舊版 `tdw_save_v1`，舊鍵保留不刪）
- 片頭動畫（可跳過、看過會記住、主選單可「重看片頭」）、會動的標題背景

### 舊存檔的關卡對應（v2.0 的 7 關 → v2.1 的 16 關）
v2.0 存檔（`dino_save_v1`，版本 v < 4）第一次讀入時自動轉換，**只會轉換一次**；原本的關卡進度另外備份在存檔的 `legacy7` 欄位，舊鍵 `tdw_save_v1` 也保留不刪。

| v2.0 關卡 | v2.1 關卡 |
|---|---|
| 第 1 關 史前叢林 | 1-1 叢林小徑（第 1 關） |
| 第 2 關 迷霧沼澤 | 2-1 迷霧沼澤（第 4 關） |
| 第 3 關 化石峽谷 | 3-1 化石峽谷（第 7 關） |
| 第 4 關 冰河時期 | 4-1 冰河時期（第 10 關） |
| 第 5 關 火山地帶 | 5-2 火山地帶（第 13 關） |
| 第 6 關 恐龍巢穴 | 6-2 恐龍巢穴（第 15 關） |
| 第 7 關 暴龍王座 | 7-1 暴龍王座（第 16 關） |

- **星數**：舊第 n 關的星數搬到對應的新關卡。
- **解鎖進度**：舊存檔能玩到第 n 關，新版就能玩到對應的新關卡，以及它之前的所有新關卡（例如舊的「已解鎖第 4 關」→ 新版 1-1 到 4-1 都能玩）。中間新增的關卡沒有星數，可以回頭補打。
- 圖鑑、擊倒數、化石、成就、道具、音量設定全部原樣保留；新增的英雄（預設獵人）與收服紀錄自動補上。
- 更早的「守護之塔」存檔（`tdw_save_v1`）會先轉成 7 關格式，再依上表對應。

## 美術與音訊
- 所有圖像與影片以 Grok Imagine 生成，原圖在 `art/src/`（不會被網頁載入），處理工具 `art/tools/process_art.py`（去背、裁切、壓成 `img/*.webp`）。
- 音樂與音效全部是免費可商用授權（CC BY 4.0 / CC0），建置工具 `art/tools/build_audio.py`。完整來源與授權見 [CREDITS.md](CREDITS.md)。

## 開發
純 HTML/CSS/JS，無建置步驟：`python3 -m http.server` 後開啟 `index.html`。
- `js/levels.js` 關卡與章節資料、`js/v21.js` 英雄／馴服／進化／天氣／夜晚／魔王技能、`js/game.js` 遊戲主程式、`js/audio.js` 音訊、`js/credits.js` 製作名單
- 測試（需 playwright）：`tests/play.py URL DEVICE OUT`（六種尺寸實機流程）、`tests/sim.py URL LEVEL [hunter|tamer]`（平衡：有英雄、不用技能與道具的自動對戰）、`tests/levels_shots.py URL OUT`（每關截圖）
